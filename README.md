A [make.fun](https://make.fun/bounty/u-po-pu-ridiculous-at-first-glance-real-by-the-second-9a97d12a) entry for
"Ridiculous at First Glance, Real by the Second": one sentence, at most 200
characters, pitching a bizarre startup idea that sounds ridiculous at first
glance but makes sense as a real business.

## The entry

> We rent cars that are already dented, so nervous drivers pay extra for the one rental nobody can blame them for scratching.

123 characters, one sentence, no trailing newline.

## How it works

`main.ts` (Node 22, standard library only, no network) writes the pitch
deterministically to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).

```sh
node main.ts
```

`candidates.md` holds eight original candidate pitches, each scored against
the house judge's five criteria, with the reasoning for the final pick and
the revision history (v1 → v2 → v3).
